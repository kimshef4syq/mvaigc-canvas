# 安装与调用 Agent 技能

## 安装入口

打开画布 Agent 对话面板，进入右上角菜单 →「技能与插件」。先填写安装 ID，例如 `film-director`，再选择来源：

- **从文件夹安装**：选择根目录包含 `SKILL.md` 的单个技能文件夹，无需压缩。
- **从 ZIP 安装**：选择本地 ZIP。ZIP 根目录直接包含 `SKILL.md`，或只包含一个内有 `SKILL.md` 的技能目录。
- **从 HTTPS 地址安装**：填写直接返回 ZIP 的 HTTPS 地址，不支持跳转。SHA256 可选；填写后会核对下载文件。

安装 ID 最长 80 个字符，只允许小写字母、数字、连字符，且以字母开头。同 ID 再次安装会更新，并保留上一版本供恢复。已禁用的技能更新后仍保持禁用。

## 技能包格式

```text
film-director/
├── SKILL.md
└── references/       # 可选，附带参考资料
    └── shots.md
```

最小可用 `SKILL.md`：

```markdown
---
name: 电影分镜导演
description: 将故事拆解为有连贯性、可执行的镜头清单。
trigger-words: [电影分镜, 镜头拆解]
---
先确认故事目标、时长和人物，再逐镜头给出景别、动作、运镜与衔接。
需要附加参考时读取 references/shots.md。
```

名称、描述、正文均应填写。可选 `allowed-tools` 声明工具要求，但声明不会自动授权或注册工具。此系统安装的是指导文档和资源；不会自动执行技能中的 Python、Shell 或 Node 脚本。因此，依赖其他产品专属工具的 Skill 可以安装，但功能未必可直接使用。

包总量最多 32 MiB、512 个文件，单个文件最多 2 MiB；`SKILL.md` 另有 128 KiB 限制，前端正文上限 100,000 字符。禁止符号链接和越界路径。

## 在对话中使用

1. 在输入框输入 `/`，显示所有已安装技能；禁用、格式无效的技能会标明状态，不能选用。
2. 继续输入名称、ID 或描述中的关键词筛选。
3. 上下键选择，Enter / Tab 或鼠标点击插入 `/安装ID `。Escape 关闭列表。
4. 补充任务后发送，例如 `/film-director 把这个故事拆成 8 个镜头`。

旧写法 `$film-director 任务` 和 `使用 film-director 技能……` 仍可使用。未明确指定时，Agent 也会根据技能触发词和任务上下文选择技能。

「使用此技能」按钮仍插入 `$安装ID`，与斜杠调用进入同一技能路由。输入 `/` 会重新读取列表，因此安装、启用或卸载后无需重启。斜杠列表针对应用内置 Agent 对话框；外部 Agent 使用其自身的技能机制。

## 内部流程

Tauri 将技能复制或解压至应用数据目录的 `extensions/skills/<安装ID>`，检查资源并生成版本哈希。前端解析 YAML 元信息、加载已启用技能索引；明确调用时优先选择，正文按需进入任务上下文，附带文本通过 `skill_read` 读取。技能不会绕过宿主审批和画布执行约束。
