# 视频节点 → 外部智能体：实现与验证记录

日期：2026-10-25。对应计划：`docs/superpowers/plans/2026-10-24-video-agent-launch-and-hypit-simplification.md`。

## 已实现

- 有可用视频的上传/生成节点工具栏提供「用智能体复刻此视频」；连接面板提供不带参考的「打开工程智能体」。
- 首次选择 Claude Code / Codex CLI、快速复刻 / 完整制作；成功后记住偏好。默认打开 macOS Terminal，不修改模型、Router、全局技能或全局 MCP。
- 按 projectId 复用工程，兼容旧 slug 目录；重命名不另建工程。
- 固定启动时的资产版本；本地导出按内容寻址、验证缓存，原始视频不被缩略图替代，也不覆盖旧终端参考。
- 每次启动有独立、项目绑定的只读任务清单与私有 MCP 描述符。另一连接替换旧连接后，旧描述符不能指向新画布。
- 机器需一次性具备 Node/npm、所选 CLI 和官方 Hypit 技能。应用从自己的发布资源准备有版本的 Provider，使用锁定依赖、局部技能及保留用户配置的 Runtime 合并；不依赖开发仓库路径。
- 新入口复用画布 mvaigc 登录，使用与画布连接同生命周期、可撤销且账号绑定的本地授权。长期账号密码不复制到 Hypit。Provider 每次请求读取私有授权文件，已有 Worker 也能读取更新后的授权。
- 版本变化不静默更新工程；对话框「更多选项」提供显式制作环境升级。
- 准备后显式选择 Runtime，并检查真实 `canvas.mvaigc` Endpoint。失败恢复原 Runtime 与 Runtime 选择，不把 project-only doctor 的成功当成 Provider 成功。
- SDK 测试真实加载 supports/start/poll/collect 与凭据解析；图片显式 1K/4K 在提交前拒绝，输出格式仍为上游决定。
- 上游任务历史最多查 10 页、500 条。刚提交的不可见任务允许 60 秒历史延迟，其后返回明确 not_found；不无限 processing，不自动重提付费生成。
- `assets_import.operationId` 提供持久化批次回执；相同文件批次重试不重复建节点；换文件或部分删除后需明确使用新 operationId。
- 任务清单包含视觉预算、先分析再生成、快速/完整制作与回写约定。它是制作指导，不是对外部模型行为的强制执行沙箱。

1. **Rust 全量**：170 passed，0 failed，1 ignored（既有忽略项）。包括本地授权撤销/到期/切账号、第二页任务查询、项目改名、参考快照与特殊文件拒绝。
2. **前端相关**：33 项通过；覆盖视频启动编排、启动期间切项目、参考版本快照、物料桥接、权限、导入验证与持久化回执。新增启动取消订阅逻辑后，启动编排的 6 项再次通过；连接面板、播放工具栏、播放条和进度遮罩的 13 项回归检查也通过。
3. **Provider**：35 项通过；使用真实 SDK，包括 capability supports 与短期授权文件续用。不是只测两个手工构造的对象。
4. **实际隔离工程安装**：在系统临时目录从空工程安装固定版本依赖，复制两种客户端的项目局部 Hypit 技能；实际运行 `hypit runtime use` 和 `hypit doctor --runtime ... --endpoint canvas.mvaigc --json`，返回 ok=true、0 diagnostics。
5. **实际失败恢复**：移除测试授权后准备失败，得到 RUNTIME_CREDENTIAL_MISSING；原 Runtime 和选择文件逐字节恢复。提供测试授权后重试成功。另实际启动了没有生成任务的隔离 Worker，修改服务地址后准备成功并刷新空闲 Worker；恢复原地址成功。存在提交/工作/保存任务时拒绝刷新，不中断付费任务。
6. **浏览器入口交互**：使用真实启动按钮和真实前端编排、模拟 Tauri IPC。选择 Codex 后核对传入 connectionId/projectId/nodeId/assetId/referencePath，窗口关闭并持久化 Codex 偏好；第二次点击直接再次发起启动请求，不再显示首次选择；这不等于验证了真实 Terminal 或真实 MCP 会话。
7. **构建**：TypeScript/Vite 生产构建、Cargo check、git diff --check 通过。
8. **桌面程序**：已成功编译并启动，读取到真实工程和视频节点。当前电脑自动化无法取得窗口前台焦点，坐标/双击操作被工具拒绝，因此不能把原生按钮→终端的完整交互标为通过。

## 验证中发现并修正的问题

- `npm file:` 默认链接让 Provider 从共享缓存解析依赖失败：改为 `--install-links`，工程得到独立安装、有版本的包。
- 未选 Runtime 的 doctor 只检查 Results，曾出现“成功但没有检查 Provider”：改为显式 Runtime 与 Endpoint。
- Env CredentialStore 的所有权是 `env`，不是任意配置别名：修正引用并用真实 doctor 验证。
- SDK 会按 dataRoot 直接复用 Worker，不检查配置/代码变化：配置变化时先查任务状态，只刷新空闲 Worker。
- 长驻 Worker 会保留旧环境变量令牌：改为每次读取稳定私有授权文件，避免重开终端后仍使用已撤销令牌。
- 旧历史条目的顶层 localVideoUrl 可能陈旧：素材目录改为取当前展示条目的路径，切换历史时同步本地路径。
- 准备过程中切换画布：前端撤销原连接，后端在真正启动前重新检查。

## 使用与边界

正常使用：打开画布 → 选中视频 →「用智能体复刻此视频」→ 首次选择智能体 →「准备并打开」。以后默认一键；旁边箭头可换智能体或制作方式。

已有只读 analysis 连接会保留权限，不能回写；需要时在连接面板显式改为 collaboration。新建连接默认协作：读取自动执行，回写仍走原审批。

已有旧工程的自定义服务、BRIEF、脚本和成品保留。安装失败可能留下已下载的依赖/缓存，但不删除用户工程；Runtime 验证失败会恢复配置与选择。跨 Provider 版本升级必须显式进行。

未推送、未发布、未升级用户 CLI 或 Router。macOS 终端仍可能显示 CLI 自身的目录信任或登录提示，没有绕过权限。
