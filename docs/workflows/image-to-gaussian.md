# 图片生成 3DGS

1. 设置 → ComfyUI → 新增自定义工作流，服务器填写 `http://192.168.0.103:8188`。
2. 输出类型选择 **3DGS**，导入同目录的 `idol_image_to_splat.json`。
3. 图片输入映射为节点 `2`、字段 `image`；输出节点填写 `["16"]`；种子映射为节点 `12`、字段 `seed`。不需要提示词映射。
4. 在画布创建 **3D 高斯**节点，将生成图片节点或素材上传节点连接到它的左侧输入端口，每次只连接一张图片。
5. 选择工作流，点击 **生成 3DGS**。节点显示提交、排队 / 生成、保存、完成或错误状态。
6. 完成后资产自动进入本地高斯资产库并被当前节点选中。点击现有的 **在 Chrome 中编辑** 按钮打开 SuperSplat。

生成任务 ID 随画布项目保存。重新打开画布会继续查询已提交任务；查询或下载失败后可点击继续查询 / 重新下载，不会再次提交生成。提交响应前中断且未取得任务 ID 时，需要先检查服务器队列，避免重复生成。

本次工作流保留原有预览图片和转台视频分支，主结果只取节点 16 的 PLY。当前不将这些附属输出创建为画布节点。

下载使用桌面 HTTP 通道，最大 128 MiB，并检查 PLY 高斯属性。原始 PLY 保存在现有 IndexedDB 高斯资产库中。网页模式不支持提交生成。
