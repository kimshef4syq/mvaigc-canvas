# 当前画布制作约定

- 使用本工程的 Hypit 技能和本地 node_modules/.bin/hypit；不要改用户全局技能、模型或 Router。
- task.json 中 projectId 和 assetId 是本次任务身份，referencePath 是已经导出的原始视频。不要因画布切换而改用其他项目。
- 默认快速复刻：先用 ffprobe 等工具读取元数据，提取 8–12 个代表帧到一张压缩总览，读一张总览后给出简短方案。只在需要时补充少量局部，复用已有分析；不要连续读取多套相同视频拼图，不默认读取频谱图。
- 图片必须走视觉输入，绝不将 Base64 打印为文本。若当前模型/网关无法真正识图，说明问题并停止视觉判断，不猜测已看见的内容。
- 有语音需求再转写。完整制作模式按需使用多镜头、字幕、配乐与合成；不一次性加载所有参考文档。
- 用户未给创作目标时先问目标；未授权生成前不提交付费任务。已有明确生成授权时继续执行，不固定增加确认门。
- 复刻提交前必须在本对话里问用户三件事：模型、分辨率、时长。用 task.json 的 `capabilities.videoModels` 列出的范围，不要自行假定或沿用上一次的选择：
  - `MiniMax-H3`（元素 `h3:ReferenceVideo`）：4–15 秒，`768P` / `2K`，不支持生成音频。
  - `Seedance-2.5`（元素 `seedance:ReferenceVideo`，`model="2.5"`）：4–30 秒，`480p` / `720p` / `1080p`，可 `generate-audio`。
  用户没答就等，不要默认挑一个；选好后按对应元素写组合，不把两个模型的名字混用。画布侧不支持 Seedance 的 web-search 与 person-reference，需要时明确说明不可用，不要假装支持。
- 参考时长超过单次模型能力时给出片段或拆镜方案，不悄悄截短。图片输出仅 2K，格式由上游决定；视频分辨率按用户所选模型档位。先用 plan 核对能力，显式分辨率或格式要求无法满足时提交前说明。
- mvaigc 授权来自本会话环境变量，由 runtime credential-store-env 读取，不需要登录 Hypit 账号库；不要显示、读取或写出令牌。环境准备由画布管理，不手工覆盖 Runtime。
- 一旦取得远端任务 ID 就保留。网络失败先查已有任务，不重新提交付费生成；结果未知应说明。上游仅返回“生成失败”时不能擅自解释为审核、余额或超时。
- 先展示成品位置与可预览结果。用户说“推回画布”后，先确认连接权限；若当前为 analysis 模式，说明需要在画布连接面板改为 collaboration，不绕过限制。然后通过 storyboard_canvas.assets_import 一次导入一批产物并打组；每批传稳定 operationId（例如 taskId:final），重试保持相同 ID 和文件清单；同一批已成功回写不要用新 ID 再次导入。
- 成品成功但导入失败，只重试导入，不重新生成。画布不可用时保留成品与任务 ID，告知从原项目重新打开连接。
- 所有观察事实与推测区分记录。分析结果写到 reference brief，以后复用，不反复读图撑大上下文。
