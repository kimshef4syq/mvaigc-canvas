# 截图清单（给用户）

目标：把「活体实机录屏」里被重绘的界面校正成真实产品。每一张截图我会按真实布局与文案重画，所以截图的**信息量**比好看更重要。

## 怎么截

- 浏览器窗口最大化，页面缩放到 **100%**（不要 90% / 110%，避免文字被缩放）。
- **整窗截图**：包含左侧导航栏、顶部栏、右侧面板——不要只截中间内容区。
- 1440 px 宽以上；Retina 屏直接截 2× 也行（我会缩到 1×）。
- 暗色主题为主；如果有亮色主题，每个页面再来一张。
- 截图里不要有真实客户名 / 手机号 / 私信；有的话打个码或换成示例项目。
- 每张图请顺手标一下**页面名**（比如 `01-我的项目.png`）。

## 需要哪几张（8 张）

| # | 页面 | 要点 |
|---|---|---|
| 1 | 我的项目 | 项目卡片的字段（封面、类型标签、时间、状态）、筛选/排序、右上角按钮 |
| 2 | 剧本详情 / 上传剧本 | 剧本文本区、右侧 AI 面板（解析按钮、统计项、进度） |
| 3 | 分镜列表 | 一张分镜卡的全部字段（镜号、时长、描述、台词、缩略图比例）、列表密度 |
| 4 | 无限画布 | 节点长什么样（标题栏、图标、内容区、连线、端口）、工具栏、缩放控件 |
| 5 | AI 创作 · 图片/视频生成 | 参数面板（模型、比例、张数、时长）、生成中的进度样式 |
| 6 | 配音工作台 | 波形样式、音色选择、时间轴、字幕对齐 |
| 7 | 音乐创作 | 候选轨道卡片、试听/选用按钮、风格标签 |
| 8 | 成片预览 / 导出 | 预览窗、时间线、播放头、导出按钮与导出设置 |

## 另外三样（不是截图）

- Logo 矢量原件（SVG / AI / 透明 PNG）。
- 品牌字体（有规范就给，没有我用 Inter + 苹方）。
- Slogan 定稿：片尾用哪一句。
