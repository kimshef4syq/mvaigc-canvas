# MOTION — 融媒视界 51 s 动态描述（一镜到底）

> 一句话：**没有一次硬切**。镜头永远在屏幕里连续移动，每一次换页都是"界面自己变形"——按钮撑开、卡片推入、面板滑出、节点生长、视频撑满。观众感觉是在看一个人连续操作，而不是在看剪辑。

- 规格：1920×1080 / 30 fps / 51 s / 无配音（字幕＋配乐）
- 节奏：**88 BPM**（1 拍 ≈ 0.682 s），全片 ≈ 75 拍。慢—中—亲密—加速—慢，一条速度曲线，不平均。
- 机位：2.5D（`s = 1/(1/z − z₀)`），zoom 1.0 → 2.3，**只推不切**；快移时才有方向性运动模糊（速度 > 30 px/帧才起糊，慢推永远清晰）。
- 缓动：UI 用 `cubic-bezier(.22,1,.36,1)`（快出慢收）；镜头用 log 空间插值（推近时速度均匀、不会"前快后慢"）；节点弹入用 spring（k=1.2, 阻尼 0.75），按钮按压 0.96×、回弹 1.02×。

## 2. 五个转场（全部"介质内"，没有一次硬切）

1. **按钮撑开成圆**（8.0 s）：主页「开始创作」的涟漪 → 圆形遮罩铺满 → 里面已经是影视工作流页。遮罩的圆心就是按钮圆心，观众的视线不用跳。
2. **抽屉槽交接**（13.8 s / 17.6 s）：Mambo 对话框与技能管理面板共用同一个右侧抽屉槽；对话框收窄的同时技能面板撑开，宽度之和恒为 400 px。
3. **面板滑出＋纵向推入**（21.4 s）：技能面板滑出画外，新页面从下方上浮接位（纵向 push），像手机换页。
4. **卡片 log-zoom＋匹配剪辑**（26.4 s）：项目卡缩略图放大成画布，卡里的"分镜网格"与画布的"节点网格"同一密度，放大过程中无缝替换。
5. **节点撑满全屏**（40.6 s）：镜头推进视频节点，节点边框被推出画外，视频画面继续放大到全屏——这就是用户要的"放大看视频"，且不需要切。

## 3. 节奏（一条速度曲线，不平均）

- **0–8 s 慢**：主页给呼吸，镜头只推 0.8 个 zoom 单位。
- **8–13 s 中**：页面切换与卡片浮入，每拍一个动作。
- **13–21 s 亲密**：Mambo 段镜头几乎不动，靠 UI 微动作（光球、眼睛、胶囊），是全片"安静"的一段。
- **21–34 s 加速**：项目页 → 画布 → 节点生成，动作密度从每拍 1 个升到每拍 2–3 个。
- **34–40 s 最快**：连线、打字、进度，鼓点加倍。
- **40–51 s 慢下来**：撤鼓，只留钢琴＋pad，最后 0.6 s 近静默再收。

## 4. 光标与微交互（丝滑的关键）

- 光标永远走**贝塞尔曲线**，速度有加减速（easeInOut），不瞬移；点击有 0.96× 按压与回弹。
- 悬停有 120 ms 的发光过渡；任何元素都不做"硬出现"，最小入场 0.16 s。
- 打字有真实节奏（0.055–0.06 s/字），不是匀速刷字。
- 节点/卡片落位一律 spring，回弹幅度 ≤ 2%，避免"果冻感"。

## 5. 抽象化处理（营销插画）

影视工作流的 6 张功能卡原本是动漫人物插画。按你的要求**用抽象化代替**：每张卡右侧是一块**抽象渐变构图**（同品牌紫＋青，低多边形/同心圆/粒子带三种母题），不加人物、不加字，只作为"氛围块"。这样既不假装是产品原图，也保持画面丰富度。

## 6. 音画同步

- 88 BPM，四段（主页 / 工作流 / 画布 / 成片），段间用 tom fill＋crash。
- 每个 UI 动作都有对应 foley（click / pop / whoosh / tick / chime），全部落在拍点或拍点的 1/2 上。
- 全片两处近静默：13 s 前（Mambo 出现前 0.4 s）与 47 s（视频最后一帧前 0.6 s）。

## 7. 交付前自检

- 无黑帧、无 NaN；镜头 zoom 连续（无跳变）；每次换页前后一帧的画面元素能"对上"（遮罩圆心/抽屉槽/网格密度/节点边框）。
- 全片一镜到底检查：随机抽 10 个转场中点帧，看是否有一帧是"两页各占一半"的硬切感。
- 字幕不与光球/节点/光标重叠；每条 ≥1.8 s。
