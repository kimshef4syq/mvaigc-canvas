# TREATMENT — 融媒视界 MEDIA VISION 产品发布片（用户脚本版）

- 风格：Living Screencast 活体实机录屏（`styles/living-screencast/STYLE.md`）
- 45 s · 1920×1080 · 30 fps · 无配音（字幕＋配乐）· 中文
- 主角：光标（用户）＋ 产品自带的小宠物 Mambo（智能助手）
- 产品：融媒视界 mvaigc.cn — 一站式 AI 内容创作引擎

## 1. 结构（用户口述，照做）

1. **主页**：整页展示（顶部三条价值主张、品牌标、AI 光球、「开始创作」、Slogan、快速创作 8 卡、作品展示），镜头随页面下移。
2. **点「开始创作」** → 进入 **AI 创作** 页（模式标签、提示词框、参数、生成按钮、最近作品）。
3. **无限画布**：先给项目卡片列表，选「城市之光」进入画布。
4. **画布**：节点从无到有 → 点「开始生成图片」→ 四张图生成 → 图片之间连线 → 出现视频节点 → 输入提示词 → 生成视频。
5. **放大视频**：镜头推入视频节点，切到全屏，单独看这支视频，片子结束。

## 2. Logline

一个想法，从主页开始，在画布上长成一支片子。

## 3. 章节与机位

| 章节 | 时间 | 机位 |
|---|---|---|
| 01 主页 | 0–9.6 | 全窗，镜头随页面下移，最后停在「开始创作」 |
| 02 AI 创作 | 9.6–14 | 全窗 → 轻推提示词框 |
| 03 无限画布 | 14–34.6 | 列表全窗 → 进画布推近节点 → 生成图/视频时微推 |
| 04 成片 | 34.6–45 | 推入视频节点（log-zoom）→ 匹配剪辑到全屏视频 |

## 4. 字幕（7–9 条，无配音）

一站式 **AI 内容创作引擎** / 点「开始创作」，进入 AI 创作 / 无限画布，所有素材**一个画布** / 节点从无到有 / 点「开始生成图片」 / 图片连起来，**就是分镜** / 输入提示词，生成视频 / 成片，**就在画布里** / 融媒视界

## 5. 声音

- 音乐 90 BPM，四段对应四个章节；章节接缝 tom fill＋crash。
- foley：点击、粘贴、节点弹出、连线生长、生成完成 chime、镜头推入 whoosh。
- 无配音；字幕烧字＋导出 `.srt`。
